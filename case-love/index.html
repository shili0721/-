3.2 抽卡机制构成

  • 卡池类型：常驻池 / 活动池
  • 概率公示：3 星 / 4 星 / 5 星 / 6 星分层，6 星中分为常驻卡面 / 限定卡面（低概率）
  • 保底机制：6 星保底（100 抽必出 6 星，但不一定是限定）+ 限定保底（140 抽得到的书简兑换限定卡面）
  • 付费结构：免费小熊（慢）/ 充值小熊（快）/ 抽卡礼包 / 月卡

3.3 逐系统拆解

系统 ①

抽卡氪金系统

机制
玩家在拥有资源之后可以参与抽卡，满 100 抽可以获得一张随机 6 星，6 星卡里面会出常驻卡面 / 限定卡面。
交互
玩家囤资源、计算微氪后获得收益，选择性价比最高的时间进行氪金、晒结果。
体验
稀缺资源 → 抽卡期待 → 抽卡后：狂喜 / 失落。
策划为什么这么设计
纯肝党只能参加小部分卡池，保证自己可以拿到卡；氪金党氪金金额过大，部分玩家负担不起，因此大部分玩家都选择肝 + 氪——氪金部分可以保证 ARPPU，肝日活可以保证用户粘度。
系统 ②

书简保底兑换商店

机制
抽卡抽数 1:1 兑换书简，如果 140 内抽没有抽到玩家想要的卡面，就可以拿 140 书简兑换想要的卡面。
交互
玩家抽卡攒书简、计算这次抽卡是继续抽还是拿书简换保底离开。
体验
安全感：知道自己多少资源敢下池子。
策划为什么这么设计
保证付费数量，当玩家资源数量不足时，知道氪金多少可以拿到卡，减少因抽不到卡面破防而流失的用户。

3.4 预测体验（沙盘推演：改一个机制会怎样）

改动玩家变化体验变化
去掉 6 星保底，但是概率变高 从「算着花」变成「赌着花」，短期付费冲动可能涨，但沉没成本的安全没了 开卡从「倒计时狂欢」变成「随缘」，期待感被稀释；单次爽感可能上升：「欧」的瞬间更多；长期焦虑上升，越抽越怕「这把没保底会不会血亏」
6 星保底门槛变低，但是取消限定保底 轻 / 中度用户更愿意小氪，重度用户回到「赌一把」心态，一旦连续歪卡，信任损耗更狠 轻 / 中度玩家早出卡有正反馈，抽卡爽感提前；重度玩家没抽到限定卡极易转去吐槽 / 弃坑

3.5 策划为什么这么设计

拉 ARPPU

低概率 + 限定，逼中氪以上用户为「限定卡面」持续投入。

控流失下限

保底 + 限定兑换，防止非酋彻底弃坑，保住长线 LTV。

制造期待感

卡池周期 + 囤资源机制，把日活变成卡池周期的锚点，拉长游戏生命周期。

拆解路径：先记录情绪峰值 → 找到触发它的那一步操作 → 拆到可配置的参数（概率 / 保底 / 兑换）→ 再做一次反事实推演：把某个参数改掉，玩家行为和情绪会怎么变。
