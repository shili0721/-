# 玉石刮一刮 · 翡翠原石模拟

一款**纯前端、零依赖、单文件**的「赌石」模拟经营小游戏。玩家用有限本金购入原石，一刀一刀刮开石皮，在信息逐步揭露的过程中做出「直接卖整料」还是「取料加工成成品」的决策，体验赌石"一刀穷、一刀富"的博弈快感。

> 本项目由我个人独立设计与开发：玩法机制、经济数值系统由我设计，代码借助 AI（vibe coding）辅助实现，并经过多轮联调与数值校准。

---

## 一、玩法流程

```
选购原石  →  刷子刮开石皮  →  信息逐步揭露、实时估价  →  决策
                                                    ├─ 直接卖整料
                                                    └─ 取料加工，摆放多个成品出售
```

1. **选购原石**：4 种场口料（普通 / 精品 / 稀有 / 王者），价格与出货概率不同，赌性递增。
2. **刮石**：按住鼠标拖动，用可调大小的刷子擦开石皮，露出内部翡翠。刮开越多，估价越准，但每刮一格都消耗成本。
3. **实时估价**：左侧价目牌实时更新「直接售卖价 / 打成品预估价 / 累计刮石成本 / 纯利润」。
4. **裂缝惩罚**：刮到裂纹会即时扣钱（带冷却，避免连续暴扣）。
5. **两种变现路径**：
   - **直接卖整料**：按当前料面价值折价出手，快但价低。
   - **取料加工**：在露出的好料区放置戒面 / 平安扣 / 挂件 / 玉镯等成品（可缩放、不可叠放、需完全落在料内且翡翠率达标），加工卖价更高。
6. **破产判定**：资产买不起任何原石时游戏结束，可重开。

## 二、技术亮点

这个项目**没有调用大模型**，游戏内容全部由**程序化算法实时生成**，AI 在其中扮演的是「开发协作者」角色。核心技术点：

### 1. 程序化内容生成（Procedural Generation）
- **分形噪声 `fbm` + 值噪声 `vnoise`**：每块原石的翡翠横截面、石皮纹理、矿点、发丝状裂纹都是实时算法生成，**没有一张贴图**，每块石头独一无二。
- **翡翠横截面 `genJade`**：随机生成若干"翠块"（位置 / 大小 / 旋转 / 种水 / 颜色），叠加噪声扰动边缘，模拟真实翡翠的自然分布。

### 2. 自洽的经济数值系统
- **种水体系**：豆种 / 糯种 / 冰种 / 玻璃种，各带价值系数。
- **颜色体系**：无色 / 飘花 / 紫罗兰 / 苹果绿 / 阳绿 / 帝王绿，6 级色系数。
- **价值公式**：`单格价值 = f(种水系数, 颜色系数, 品质, 裂缝折损)`，聚合出整料价值。
- **双变现定价**：整料直售价（折价）与取料加工价（受成品面积、种水、颜色、裂纹率、市场浮动共同影响）分别建模。
- **成本与风险**：购入成本、逐格刮石成本、裂缝罚金、破产线，构成完整的收支闭环。

### 3. 交互与渲染
- **Canvas 双层绘制**：翡翠层 + 石皮层，用 `destination-out` 合成实现"刮开"的擦除效果。
- **取料校验**：放置成品时实时检测「是否越界轮廓 / 是否与已放置成品重叠 / 翡翠率是否达标」，非法放置爆红提示。
- **多边形内判定（射线法）**：判断刷子与成品是否落在不规则石头轮廓内。

## 四、技术栈

- **纯前端**：原生 HTML + CSS + JavaScript，**无任何第三方依赖、无需构建**。
- **渲染**：HTML5 Canvas 2D。
- **算法**：分形/值噪声（程序化生成）、射线法多边形内判定、Canvas 合成擦除。
- **单文件**：全部逻辑集中在一个 `index.html`，双击即可运行。
