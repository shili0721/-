# ✦ 星盘识别 Demo（本命盘解析）

上传一张占星星盘截图，自动识别其中的**出生信息**，再用**精确星历**重新计算并输出：

- 出生信息（姓名 / 日期 / 时间 / 地点 / 分宫制）
- 四轴：ASC / MC / DES / IC
- 十大行星位置（星座度数 + 落宫 + 是否逆行）
- 托勒密相位（全部列出，含精确 orb 度数、出/入相位）
- 特能：完整传统尊贵体系（庙 / 旺 / 陷 / 弱 / 三分主 / 界主 / 面主、互容 / 互溶、焦伤 / 日光束下 / 核心、东出 / 西入、逆行、昼夜盘及尊贵总分）

## 快速开始

**方式一（零依赖，推荐）**：直接双击打开 `index.html`。

**方式二（本地服务器，需 Node）**：
```bash
node serve.js
# 浏览器打开 http://localhost:8080
```

打开后点击 **「载入样例（刘☆秀 2005-08-06）」** 即可立即看到完整解析结果。

## 两种输入方式

1. **上传星盘图片 → AI 识别**
   在「视觉接口设置」中填写任意 *OpenAI 兼容* 的多模态接口（`Base URL` / `API Key` / 支持视觉的 `模型名`，
   如 `gpt-4o`、`qwen-vl-max`、`glm-4v` 等），上传图片后点击「识别图片并生成」。
   模型仅用于**读取图片左上角的出生信息**（姓名/日期/时间/经纬度/时区）。
   设置只保存在浏览器本地 `localStorage`，不会上传到别处。

2. **手动输入出生信息**
   直接填写日期、时间、时区、经纬度，点击「生成星盘解析」。
   此方式**完全离线**、无需任何密钥。

> 说明：相位的「精确度数」和「出/入相位」等信息必须由星历计算得出（出/入相位依赖行星实时速度），
> 无法从图片像素中可靠读出。因此本 Demo 的策略是：**用图片识别出生信息 → 用星历精确重算全部内容**，
> 保证结果与专业占星软件一致。

| ASC | 天蝎 5°30′ | 天蝎 5°30′ |
| MC | 狮子 6°27′ | 狮子 6°27′ |
| 太阳 | 狮子 13°48′ · 第10宫 | 狮子 13°48′ · 10 |
| 水星 | 狮子 13°29′ 逆 · 第10宫 | 狮子 13°29′ Rx · 10 |
| 金星 | 处女 16°57′ · 第11宫 | 处女 16°57′ · 11 |
| 木星 | 天秤 14°04′ · 第12宫 | 天秤 14°04′ · 12 |
| 冥王星 | 射手 22°01′ 逆 · 第2宫 | 射手 22°01′ Rx · 2 |

四轴与行星度数、落宫、逆行状态均一致。

## 技术栈

- **星历**：[astronomy-engine](https://github.com/cosinekitty/astronomy)（纯 JS，精度达角秒级），
  采用回归黄道 / 当日真黄道（ECT），与主流占星软件一致。
- **四轴 / 宫位**：自实现 ASC、MC 公式 + Placidus 半弧迭代分宫。
- **相位 / 结构**：自实现托勒密五主相位（含 orb、出入相位）与常见相位结构识别。
- 纯前端，无需构建、无需后端。

## 文件结构

```
js/vision.js          图片识别（OpenAI 兼容视觉接口）
js/wheel.js           Canvas 星盘轮盘绘制
js/app.js             界面逻辑
serve.js              可选静态服务器
```
